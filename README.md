# thyfani.com.br

Portfólio pessoal de Thyfani Xavier, organizado como site estático multipágina.

## Estrutura

- `index.html` — entrada principal
- `sobre.html` — trajetória, posicionamento e stack
- `projetos.html` — projetos em destaque
- `laboratorio.html` — ideias e protótipos de dados/IA
- `curriculo.html` — experiências, formação e certificações
- `artigos.html` — links para textos publicados
- `contato.html` — links profissionais
- `assets/styles.css` — estilos compartilhados
- `assets/site.js` — menu mobile, navegação ativa e cursor
- `CNAME` — domínio customizado para GitHub Pages
